# magicTupper 1.1.0 Stable

Base funcional consolidada para publicación del proyecto.

## Confirmado
- Remote Play Android/Windows: H.264 para juegos, HOME mediante MTJ1/JPEG, audio PCM y mandos.
- Control táctil nativo Android.
- RCM Injector Android validado en dispositivo real: detección APX, permiso USB e inyección manual de Hekate.
- En Android TV el acceso al RCM Injector se oculta automáticamente.
- Explorador NRO incorpora `Montar XCI · próximamente` como marcador visible de roadmap; no implementa montaje en esta release.

## Publicación
Los binarios finales NRO/APK/PC Client/sysmodule y el despliegue Compose deben recompilarse desde este árbol antes de crear la release de GitHub. El paquete recompilado será la fuente para documentar hashes, rutas de descarga e instalación.
